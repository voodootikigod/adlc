## 1. Objective & Scope

Wave 1 and Wave 2 (merged in PR #1239 as `f69ed1f0`) delivered the shared `@adlc/core` primitives (`writeFileAtomic`, `acquireDirLock`, `redactSecrets`, `readVerdictSource`, `recordPromptOnlyVerdict`), the findings ledger concurrency lock (`withLedgerLock`), the static relative-import cycle detector (`findImportCycles` in `@adlc/build-gate`), the `review-calibration` witness discriminator (`discriminateWitness`), and the `@adlc/runner` human-approval cryptographic binding (`verifyHumanApprovalBinding`).

Wave 3 eliminates the remaining duplicated implementations across ADLC packages by promoting shared crash-recovery (`inflight.mjs`) and Jaccard Union-Find clustering (`cluster.mjs`) engines into `@adlc/core`, adopting `@adlc/core` prompt-only verdict helpers in `coldstart`, `premortem`, and `parallax`, adopting shared crash-recovery and symlink-preserving atomic write primitives in `hollow-test`, `review-calibration`, and `consensus-fix`, and consolidating duplicated P5/P6 evidence verification helpers inside `@adlc/runner`.

### Out of Scope
- Modifying any active frozen rail in `.adlc/tickets/` (`packages/core/lib/ledger.mjs`, `packages/build-gate/bin/build-gate.mjs`, `packages/runner/test/acceptance-human-binding.test.mjs`, `packages/rails-guard/**`, `packages/gate-manifest/lib/record.mjs`, `packages/prosecute/test/**`, `packages/fleet/lib/**`, `scripts/preflight.mjs`).
- Changing the external CLI flags, exit codes (`0` / `1` / `2`), or JSON output schemas of any package.
- Altering the on-disk inflight record schema versions (`RECORD_VERSION = 2` for `hollow-test` single-file records; `RECORD_VERSION = 1` for `review-calibration` multi-file journals).

## Acceptance Criteria

- **AC-W3-T1-1 (`W3-T1`):** `packages/coldstart/lib/verdict.mjs`, `packages/premortem/lib/verdict.mjs`, and `packages/parallax/lib/verdict.mjs` re-export `readVerdictSource` directly from `'@adlc/core'` and delegate `recordVerdict` to `recordPromptOnlyVerdict` from `'@adlc/core'` using `@adlc/gate-manifest`'s `record(...)` callback (`recordFn: ({ gate, ticket, rawData, dir }) => record({ gate, ticket, rawData, rawFiles: specPath, dir, key })`). Verify: `node --test packages/coldstart/test/prompt-only-usage.test.mjs packages/premortem/test/prompt-only-usage.test.mjs packages/parallax/test/prompt-only-usage.test.mjs`
- **AC-W3-T1-2 (`W3-T1`):** In all three `verdict.mjs` modules, caller-supplied `extra` properties cannot override `promptOnly: true`, `usageStatus: 'unreported'`, or `verdict` (enforced by `recordPromptOnlyVerdict`'s `{ ...extra, promptOnly: true, usageStatus: 'unreported', verdict }` ordering), and unit tests in `packages/coldstart/test/prompt-only-usage.test.mjs`, `packages/premortem/test/prompt-only-usage.test.mjs`, and `packages/parallax/test/prompt-only-usage.test.mjs` assert this invariant. Verify: `node --test packages/coldstart/test/prompt-only-usage.test.mjs packages/premortem/test/prompt-only-usage.test.mjs packages/parallax/test/prompt-only-usage.test.mjs`
- **AC-W3-T2-1 (`W3-T2`):** `packages/core/lib/inflight.mjs` exports `probeOwner(pid, killFn)`, `ownerStateFor(recordPid, selfPid, probe)`, `isContainedRelPath(relPath)`, `resolveTarget(repoRoot, relFile)`, `makeTempPath(targetPath, pid)`, `writeInflightAtomic(targetPath, content, options)`, `sweepStaleTemps(targetPath, options)`, and `clearRecord(recordPath)`. `writeInflightAtomic` resolves symlinks via `realpathSync` when `lstatSync(targetPath).isSymbolicLink()` is true, preserves existing file mode (`statSync(realTarget).mode & 0o777`), opens the sibling temp file with `'wx'`, calls `fsyncSync(fd)`, renames over `realTarget`, and unlinks any temp file on failure.
